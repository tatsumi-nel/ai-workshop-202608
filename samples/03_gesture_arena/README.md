# Gesture Arena

Webカメラで手を認識し、ジェスチャーで宇宙船を操作するゲームです。映像や認識結果は
外部APIへ送信せず、PC上で処理します。

## 実行

```bash
uv sync
uv run python main.py
```

初回はOSからカメラ利用の許可を求められる場合があります。カメラがない、または
許可されなかった場合は自動的にキーボード操作へ切り替わります。最初からカメラを
使わず起動することもできます。

カメラ初期化と画像認識は別プロセスで行うため、許可待ちや初期化に時間がかかっても
ゲーム画面は操作できます。`C` でカメラのON/OFF、`N` で次のカメラへ切り替え、
`Q`、`Esc` または `Ctrl-C` で終了します。カメラ準備後に `Space` を押すとゲームが始まります。

カメラを初めて使うときは、Googleが公開しているMediaPipeの手認識モデルを
`models/` へダウンロードします。これは有料APIの呼び出しではなく、以後はローカルで
推論します。講習会では講師PCで一度起動し、モデル取得まで確認しておいてください。

```bash
uv run python main.py --no-camera
```

## 操作

| ジェスチャー | 動作 | キーボード |
|---|---|---|
| 手を左右へ動かす | 手の横位置へ移動 | `←` / `→` または `A` / `D` |
| グー | レーザー発射 | `Space` |
| パー | シールド | `S` |
| — | リスタート | `R` |
| — | カメラON/OFF | `C` |
| — | 次のカメラへ切り替え | `N` |
| — | 終了 | `Q` または `Esc` |

明るい場所で、手のひらをカメラへ向けて操作してください。

## macOSでカメラが映らない場合

1. 「システム設定 → プライバシーとセキュリティ → カメラ」を開く
2. 実行に使っている `ターミナル`、`Visual Studio Code` などを許可する
3. 設定を変えたアプリを一度終了して開き直す
4. ゲーム画面で `C` を押してカメラを再接続する

外付けカメラなどがある場合は、番号を変えて試せます。

```bash
uv run python main.py --camera-index 1
```

Immersed、OBSなどの仮想カメラ映像が表示された場合も、ゲーム画面で `N` を押して
内蔵カメラが映る番号まで切り替えてください。現在の番号は `CAMERA 0 ONLINE` のように
右上へ表示されます。

`uv run python main.py --no-camera` でゲームが動き、通常起動だけで
`CAMERA OFFLINE` になる場合は、ゲーム本体ではなくカメラ権限またはカメラ番号の問題です。

## テスト

```bash
uv run pytest
```

カメラやウィンドウがなくても、ジェスチャー判定ロジックのテストは実行できます。

## AIへの依頼例

1. 「ピースサインを認識したらレーザーを2本発射してください」
2. 「左右の手で異なる操作ができるようにしてください」
3. 「隕石以外に、左右へ動く敵を追加してください」
4. 「認識中の指の骨格をカメラ映像へ描画してください」
5. 「ジェスチャー判定の境界値テストを追加してください」

`gesture_logic.py` は画像認識結果から操作を決め、`main.py` はゲームを担当します。
この境界を保って機能追加するのがポイントです。
