# Gesture Arena

Webカメラで手を認識し、ジェスチャーで宇宙船を操作するゲームです。映像や認識結果は
外部APIへ送信せず、PC上で処理します。

## 実行

```bash
uv sync
uv run python main.py
```

初回はOSからカメラ利用の許可を求められる場合があります。カメラがない、または
許可されなかった場合は自動的にキーボード操作へ切り替わります。最初からカメラを
使わず起動することもできます。

カメラを初めて使うときは、Googleが公開しているMediaPipeの手認識モデルを
`models/` へダウンロードします。これは有料APIの呼び出しではなく、以後はローカルで
推論します。講習会では講師PCで一度起動し、モデル取得まで確認しておいてください。

```bash
uv run python main.py --no-camera
```

## 操作

| ジェスチャー | 動作 | キーボード |
|---|---|---|
| 人差し指を立てる | 手の位置へ移動 | `←` / `→` または `A` / `D` |
| グー | レーザー発射 | `Space` |
| パー | シールド | `S` |
| — | リスタート | `R` |
| — | 終了 | `Esc` |

明るい場所で、手のひらをカメラへ向けて操作してください。

## テスト

```bash
uv run pytest
```

カメラやウィンドウがなくても、ジェスチャー判定ロジックのテストは実行できます。

## AIへの依頼例

1. 「ピースサインを認識したらレーザーを2本発射してください」
2. 「左右の手で異なる操作ができるようにしてください」
3. 「隕石以外に、左右へ動く敵を追加してください」
4. 「認識中の指の骨格をカメラ映像へ描画してください」
5. 「ジェスチャー判定の境界値テストを追加してください」

`gesture_logic.py` は画像認識結果から操作を決め、`main.py` はゲームを担当します。
この境界を保って機能追加するのがポイントです。
