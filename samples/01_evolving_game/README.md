# Evolving Game

参加者のアイデアを、その場でゲームへ追加するための教材です。最初から遊べる
ネオン風ブロック崩しを、AIとの対話で進化させます。

## 実行

```bash
uv sync
uv run python main.py
```

操作方法:

- `←` / `→` または `A` / `D`: パドルを移動
- マウス: パドルを移動
- `Space`: 開始、一時停止、再開
- `R`: 最初からやり直す
- `Esc`: 終了

## テスト

```bash
uv run pytest
```

## AIへの依頼例

1. 「ボールが3個に分裂するアイテムを追加してください」
2. 「耐久力が3あるボスブロックを最上段に追加してください」
3. 「コンボが続くほど画面の色と得点倍率を変えてください」
4. 「タイトル画面で難易度を選べるようにしてください」
5. 「新機能のロジックにpytestのテストも追加してください」

まず `game_rules.py` の純粋なロジックを変更してテストし、その後 `main.py` の
表示と入力を変更すると、安全に小さなサイクルを回せます。
