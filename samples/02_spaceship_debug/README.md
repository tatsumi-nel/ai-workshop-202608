# Spaceship Debug Mission

西暦2045年。探査船 `Astra` の制御ソフトに不具合が見つかりました。仕様書と
失敗するテストを手掛かりに、AIと協力して出発までに修理してください。

このプロジェクトは**意図的にバグを含んでいます**。最初の `pytest` が失敗する
ことが、正常な教材の状態です。

## 準備と診断

```bash
uv sync
uv run python main.py
uv run pytest
```

## ミッション仕様

制御ソフトは次の規則を必ず守らなければなりません。

1. 酸素・燃料・船体値は常に `0` 以上 `100` 以下
2. 燃料を消費しても残量は負にならない
3. 酸素消費量は `乗員数 × 経過分数 × 0.04`
4. 発進には「燃料80以上」「酸素90以上」「船体95以上」が**すべて**必要
5. 炉心温度が900度以上、**または**放射線量が250以上なら緊急停止
6. センサー平均値は小数を失わず計算する

## AIへの依頼例

最初から「全部直して」と頼むより、次のサイクルを繰り返します。

```text
pytestを実行し、最初の失敗について原因を説明してください。
まだコードは変更しないでください。
```

```text
原因が分かったので、最小限の修正を行い、関連するテストだけ実行してください。
```

最後に全テストを実行し、`main.py` の診断画面で `GO FOR LAUNCH` になることを
確認します。
